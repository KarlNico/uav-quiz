无人机理论刷题 · iPhone 版（PWA）部署说明
========================================

一、这是什么
------------
这是一个 PWA（渐进式 Web 应用），可以像原生 App 一样安装到
iPhone 主屏幕，支持离线使用，无需 App Store 审核。

二、部署步骤（必须 HTTPS）
---------------------------
PWA 必须部署到 HTTPS 环境才能安装到主屏幕。
以下任选一种免费方案：

方案 A：GitHub Pages（推荐）
  1. 在 GitHub 新建一个仓库
  2. 把本文件夹所有文件上传到仓库
  3. 仓库 Settings → Pages → Source 选 main 分支 → Save
  4. 等待几分钟，访问 https://你的用户名.github.io/仓库名/

方案 B：Netlify（拖拽部署，最快）
  1. 打开 https://app.netlify.com/drop
  2. 把本文件夹拖进去
  3. 自动生成 https://xxx.netlify.app 地址

方案 C：Vercel
  1. 打开 https://vercel.com/new
  2. 上传本文件夹
  3. 自动生成 https://xxx.vercel.app 地址

方案 D：自己的服务器
  把文件放到网站根目录，确保 HTTPS 可访问。

三、iPhone 安装步骤
---------------------
1. 用 Safari 打开部署后的网址
2. 点击底部「分享」按钮（方框+向上箭头）
3. 下滑找到「添加到主屏幕」
4. 点击「添加」
5. 回到桌面，点击「无人机刷题」图标即可全屏使用
6. 首次打开后会自动缓存，之后断网也能刷题

四、文件说明
-------------
index.html      主页面（含全部题库数据，离线可用）
manifest.json   PWA 配置（名称、图标、主题色）
sw.js           Service Worker（离线缓存）
icons/          应用图标

五、更新题库
-------------
替换 index.html 后，用户重新打开应用会自动更新
（Service Worker 会在下次启动时拉取新版本）。
